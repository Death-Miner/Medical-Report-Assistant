# Medical Report AI Assistant

An AI-powered application that helps users understand
medical reports in simple language.

## Features

- PDF report processing
- Image report processing
- OCR
- Medical parameter extraction
- Reference range comparison
- Normal/abnormal classification
- Simple report summary
- AI-powered report Q&A
- Conversation history
- Extraction validation
- JSON export
- Basic medical safety guardrails

## Architecture

Upload Report
→ Text/OCR Extraction
→ Parameter Extraction
→ Validation
→ Reference Range Analysis
→ Summary
→ AI Chatbot

## Technologies

- Python
- Streamlit
- PyMuPDF
- Tesseract OCR
- OpenCV
- Gemini API

## Safety

This application does not provide medical diagnosis,
prescriptions, or treatment recommendations.

Users should consult qualified healthcare professionals
for medical decisions.
